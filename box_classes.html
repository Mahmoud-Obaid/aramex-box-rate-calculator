Calculate Rate

Uses the Origin and Destination addresses above, plus the box and total weight from the Shipment Box & Weight Finder, to get a shipping rate from Aramex.

Product Group is set automatically: DOM if Origin and Destination are the same country, EXP if they differ — currently: -- select both addresses --. The Product Type list above updates to match. Payment Type is fixed as P (prepaid). Dimensions and Actual Weight come from the box calculated in Shipment Box & Weight Finder above.

Smart Box Finder

Select how many items you want to pack, enter each item's dimensions, and this tool will run a 3D packing simulation across every Class A and Class B box to find the smallest box (or combination check) that fits all items with the least amount of free space.

Please fill in all dimension fields (Length, Width, Height) for every item before continuing.
